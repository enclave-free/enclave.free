## Implementation

- Expanded the durable model-backed regression harness to mirror the authoritative four demo mappings and authoritatively enable Curated Resources for each through the local Admin API. The global mapping is a real user with `user_type_id=None`; it does not fabricate a fourth User Type. Its global Tool default is read and journaled before mutation, restored exactly during cleanup, and its effective `/session-defaults` request has no fake User Type query.
- Added stale-to-fresh Conversation journeys. After the synthetic Resource Directory is updated, context-free follow-ups for email, phone, URL, address, and secure channel must execute Curated Resources and return only the fresh value. Language is an explicit replay dimension, not a claim about live persona language. English covers all five modalities and Spanish executes an independent stale/fresh journey with the exact reported `¿Me puedes dar el email?` follow-up. Stream and non-stream paths are exercised.
- Structural Tool scoring now requires a successful completed lifecycle record from `tools` or `tool_result` deltas. Enabled/available Tool metadata, stale context, attempted calls, and failed or incomplete lifecycle states cannot produce a false pass.
- Added deterministic 11-resource inventory journeys. The scorer accepts either an exact bounded first page or exact complete coverage only when successful Curated Resources Trace metadata authoritatively reports 10/11 with `has_more=true,next_offset=10`, followed by terminal 1/11 or 0/11 metadata as appropriate. It uses boundary-aware exact names and rejects negated/qualified completeness, generic “more information” prose, wrong counts/offsets, and answer-only continuation claims.
- Evidence schema v2 records case status, pass/fatal/failure state, expected/completed counts, cleanup failures, and privacy-safe Tool lifecycle records. It omits prompts, raw arguments/results, session IDs, credentials, and customer content. A partial or fatal run cannot resemble a successful matrix.
- Fixture setup is journal-first and failure-atomic. The harness derives a deterministic valid secp256k1 x-only ephemeral Admin key, journals every created object before the next step, reconciles exact issue suffixes, and cleans partial setup as well as completed runs.
- Curated Resources Trace summaries and an allowlisted metadata object now report `returned_count`, `total_count`, `has_more`, and `next_offset`. Trace deduplication includes metadata in its identity, preserving distinct pages while still collapsing exact duplicates. This exposes bounded results without adding deterministic routing or response post-processing.
- The model replay uncovered provider output that serialized Tool intent as plain answer text. Sage's existing quarantine now scans every provider-neutral Tool label, including benign-label-then-invocation forms in one or split deltas and Args blocks following prose-like suffixes. Curly apostrophes are normalized and `I’m going to search. Tool: ...` is rejected in same- and split-delta forms before exposure. Unsafe candidates use the existing retry/fail-closed policy. Ordinary explanatory Tool prose remains streamable.

- A second rereview found five remaining gaps: fake global scoping, unexecuted Spanish constants, prose-authoritative inventory scoring, curly-apostrophe quarantine mismatch, and exit status not using final summary state. Each was reproduced with focused RED tests and corrected. The subsequent model inventory replay exposed a sixth deterministic gap—same-query pagination traces were deduplicated—then a 1-page RED/2-page GREEN regression fixed it.
- A third rereview found four narrow gaps. Inventory scoring could accept contradictory `999/999` or offset claims and the Spanish negation `No son todos`; a terminal Resource Trace called a final page “all” without scoping the count; the destructive evaluator accepted remote API origins; and an evidence-write failure happened after summary calculation. Each was pinned with a RED regression and corrected. The evaluator now accepts only loopback origins before fixture creation, validates numeric claims against successful Tool metadata, rejects the Spanish negation, and recomputes a failed summary after persistence errors. Sage reports the page count, total count, and terminal state without an unscoped “all.”
- The final closure check then identified natural-language variants outside the first numeric parser and a separate overclaim in the actual Tool result body. The scorer now rejects unsupported `999 of 999`, `next offset is 999`, and `999 more matching resources` while positively accepting authoritative `10 of 11`, `next offset is 10`, and `1 more` wording. For terminal Resource pages, the Tool result says “complete set” only at offset zero when the returned and total counts match; continuation pages instead say that this is the final page and no results remain. The regression asserts both the actual Tool result and the Trace summary.
