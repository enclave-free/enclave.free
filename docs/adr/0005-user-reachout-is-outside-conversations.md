# User Reachout Is Outside Conversations

User Reachout is an authenticated Ordinary Product Flow that lets a User contact the Operator outside a Conversation. It does not require User Approval, so pending users can ask for help, but it is not a Sage Tool and does not create Conversation Content in the current prototype. Reachout Messages are sent through the configured email path and are not persisted as support tickets or conversation threads; if reachout later becomes Sage-mediated, ticketed, or stored, that should be treated as a new decision.
